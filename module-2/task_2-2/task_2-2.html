1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants should be used when a value should not change. Variables should be used when a value needs to change later. They cannot all be constants because some values need to be changed during the program.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses change the order in which the calculations are done. The calculation inside the parentheses is done first.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. We can use methods such as toFixed() to limit the number of decimals.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We can compare them using a small difference between the numbers instead of checking if they are exactly equal.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return either true or false. We can use the result of the comparison to check whether something is true or false.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() generates a random floating-point number between 0 (inclusive) and 1 (exclusive). It can be used for generating random numbers, simulating chance events, or creating randomized behavior in applications.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus (%) returns the remainder after division. We need this operator when we want to find the remainder of a division operation or determine if a number is even or odd.
